# Merkin Blender Tools

This app folder owns Blender-side tooling for the Merkin game editor.

- `merkin_scene_bridge/` is the source add-on package.
- `merkin_scene_bridge.zip` is generated by `apps/blender/package-scene-bridge-addon.sh` and is the file to install in Blender.
- `scene-packages/` is where the game level editor writes exported level packages for Blender import.
- `start-local-hunyuan-comfy.sh` starts the existing local ComfyUI/Hunyuan3D host through a user `systemd` unit.
- `hunyuan3d_direct_blender_addon/` is the local direct Hunyuan3D Blender add-on package.
- `hunyuan3d_direct_blender_addon.zip` is generated by `apps/blender/package-direct-hunyuan-addon.sh` and is the file to install in Blender.
- `start-direct-hunyuan-server.sh` starts the direct local Hunyuan3D FastAPI server on `http://127.0.0.1:8080`.

Do not edit generated zip contents directly. Edit the source package, rebuild the zip, then install the zip in Blender.

To rebuild the Merkin scene bridge:

```bash
apps/blender/package-scene-bridge-addon.sh
```

## Local Hunyuan3D

Preferred direct path:

```bash
apps/blender/start-direct-hunyuan-server.sh start
apps/blender/start-direct-hunyuan-server.sh health
```

The Blender add-on zip to install is:

```txt
apps/blender/hunyuan3d_direct_blender_addon.zip
```

If the zip is missing or stale, rebuild it:

```bash
apps/blender/package-direct-hunyuan-addon.sh
```

In Blender 5.0, install that zip from Preferences -> Add-ons -> Install from Disk, then enable `Merkin Local Hunyuan3D`. The add-on appears in the 3D View sidebar under `Merkin Hunyuan3D` and talks to `http://localhost:8080`.

This direct path uses:

- shape checkpoint: `/home/greggles/ComfyUI/models/diffusion_models/hunyuan3d-dit-v2-0/model.ckpt`
- texture model root: `/home/greggles/ComfyUI/models/diffusers`
- direct server wrapper: `apps/blender/hunyuan3d-direct/server.py`
- official Hunyuan3D repo: `/home/greggles/ai-runtimes/Hunyuan3D-2`

Useful direct-server commands:

```bash
apps/blender/start-direct-hunyuan-server.sh status
apps/blender/start-direct-hunyuan-server.sh logs
apps/blender/start-direct-hunyuan-server.sh stop
apps/blender/start-direct-hunyuan-server.sh foreground
```

The direct server supports local image-to-3D mesh generation and texture generation by default.

Text-only generation is intentionally not enabled yet because it requires loading a separate text-to-image model.
