# Observatory Terrain Asset Sources

These runtime visual assets are checked-in public files for the Observatory layered terrain material.

## Downloaded CC0 PBR Textures

- Poly Haven `rock_ground`: https://polyhaven.com/a/rock_ground
- Poly Haven `dirt`: https://polyhaven.com/a/dirt
- Poly Haven `gravel`: https://polyhaven.com/a/gravel
- Poly Haven `mossy_rock`: https://polyhaven.com/a/mossy_rock

Downloaded maps are 2K JPG albedo, OpenGL normal, and roughness maps from Poly Haven. Poly Haven assets are CC0.

## Authored Control Mask

- `observatory_terrain_splat_rgba.png` is a deterministic RGBA splat control mask for blending the downloaded terrain layers across the existing Observatory GLB UVs.
