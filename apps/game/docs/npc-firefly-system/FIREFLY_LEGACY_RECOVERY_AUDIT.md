# Firefly Legacy Recovery Audit

Source legacy snapshot: `cd7177a`, where authored fireflies still used `gameplay.type === "firefly"`.

## Findings

- Legacy authored firefly actors existed in Solitude and Yggdrasil, not Observatory, in the checked git history before the NPC migration.
- Observatory also had a separate ambient firefly field in the older HybridObservatory path. That field was not authored as per-firefly scene actors, so it belongs to the scene firefly field contract, not stationary source actors.
- Current Solitude and Yggdrasil NPC fireflies now match the legacy authored firefly data for ids, names, dialog, positions, scale, colors, size, light parameters, sprite parameters, burst parameters, movement parameters, read-only duration, and shockwave eligibility.
- Current Observatory ambient fireflies now restore the old clustered field behavior through typed scene settings: high/ultra quality can resolve to 200 ambient fireflies, lower quality tiers resolve fewer, the field uses origin-centered terrain-following center falloff, the legacy eight-color palette, 180 radius, 2-5 terrain-relative height band, 25 max active lights, and visible legacy-style drift. Observatory no longer has authored stationary NPC firefly actors.
- The old runtime rendered one point light per authored firefly when `lightIntensity > 0` and `lightDistance > 0`, scaled by `0.16`. It also rendered one primary star sprite, plus a selected overlay sprite while selected or in conversation.
- Movement pattern was deterministic per id: `x = sin(time * wanderSpeed + phase) * wanderRadius`, `y = hoverHeight + sin(time * bobSpeed + phase * 0.5) * bobAmplitude`, `z = cos(time * wanderSpeed + phase) * wanderRadius`.
- Light-burst response used `(0.45 + burst.strength * 0.75) * lightBurstBoost`. Pillar fireflies were shockwave-enabled by id/name/author and turned toward `#ff1830` after ignition.

## Observatory Ambient Firefly Field

The older Observatory implementation used `HybridObservatory.svelte` plus `HybridFireflyComponent.svelte`, not checked-in scene actors. The recoverable legacy field parameters were:

- Field count: old checked-in `HybridObservatory` prop was `count={100}`; current authored requirement restores 200 on high-performance tiers.
- Quality scaling: legacy caps changed across history, but the system always reduced particles and lights by quality tier. Current scene data resolves `ultra_low=12`, `low=32`, `medium=80`, `high=200`, and `ultra=200`.
- Distribution: legacy placement used `Math.pow(random, 2) * radius`, which clusters near the world-origin hill with density falloff. Current scene data uses `center: [0, 0, 0]`, `terrainFollow: true`, `distribution: "center-falloff"`, and `densityExponent: 2`.
- Radius and height band: legacy Observatory used radius `180` and height range `2-5` above sampled terrain height.
- Color palette: `#87ceeb`, `#98fb98`, `#ffffe0`, `#dda0dd`, `#f0e68c`, `#ffa07a`, `#20b2aa`, `#9370db`.
- Lighting: legacy field used up to 25 active firefly lights through a dedicated lighting system. Current scene data keeps `lightCount: 25`, `lightIntensity: 50`, and `lightDistance: 500`, rendered through `ManagedLight`; Observatory sets `lightBudgeted: false` because the field already owns its quality-tier light counts.
- Interaction split: the moving ambient field is clickable when enabled. `profileChance: 0.15` assigns the first slice of the current quality-tier population to personality-backed profiles; the rest use the recovered lost-soul read-only response pool.

Observatory conversational fireflies are now generated from the moving field at runtime. Authored fixed-position NPC firefly actors are intentionally absent from this level.
