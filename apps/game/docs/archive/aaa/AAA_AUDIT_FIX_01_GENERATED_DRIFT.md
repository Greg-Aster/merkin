# AAA Audit Fix 01 - Generated Drift Blocking Release Gate

## Finding

`pnpm --dir apps/game check:generated-drift` fails. The failure currently reports drift in:

- `apps/megameal/public/generated/runtime-game-assets/scenes/yggdrasil.runtime-scene.json`
- The drift is around `settings.level.renderProfile.qualityTiers.desktop.postProcessing`, specifically ambient occlusion and post-processing pass ordering/counts.

Because `release:gate:ci` runs `check:generated-drift`, this is a release-blocking integration failure.

## Mission

Make generated runtime artifacts match the current source-of-truth pipeline. Do not hand-edit generated JSON unless the pipeline itself is wrong and the edit is part of fixing that pipeline.

## Primary Files

- `apps/game/src/threlte/editor/scenes/yggdrasil.scene.json`
- `apps/megameal/public/generated/runtime-game-assets/scenes/yggdrasil.runtime-scene.json`
- `apps/game/scripts/check-generated-drift.mjs`
- `apps/game/scripts/cook-runtime-assets.mjs`
- `apps/game/scripts/lib/runtimeAssetCookManifest.mjs`
- `apps/game/scripts/lib/runtimeSceneManifest.mjs`

## Work Steps

1. Reproduce the failure:

```bash
pnpm --dir apps/game check:generated-drift
```

2. Regenerate reviewed runtime artifacts:

```bash
pnpm --dir apps/game cook:runtime-assets
```

3. Run drift again.

If drift remains after regeneration, inspect the cook path and determine why the expected manifest generated by `check-generated-drift` differs from the written artifact. Fix the source pipeline, not the symptom.

4. Verify whether the ambient occlusion fields are supposed to ship in the desktop Yggdrasil render profile. If yes, ensure the source scene, cooked scene, and drift expected output all agree. If no, remove it from the source scene/profile and regenerate.

5. Confirm generated artifact updates are intentional and scoped.

## Acceptance Criteria

- `pnpm --dir apps/game check:generated-drift` passes.
- `pnpm --dir apps/game release:gate:ci` no longer fails on generated drift.
- Yggdrasil source scene and cooked runtime scene agree on render-profile ambient occlusion fields.
- No generated count files are hand-edited without a source pipeline explanation.

## Validation

```bash
pnpm --dir apps/game cook:runtime-assets
pnpm --dir apps/game check:generated-drift
pnpm --dir apps/game audit:engine
pnpm --dir apps/game release:gate:ci
```

## Handoff

Report:

- Root cause of the drift.
- Generated files changed.
- Whether ambient occlusion remains enabled for Yggdrasil desktop.
- Commands run.
- Any remaining generated artifact risk.
