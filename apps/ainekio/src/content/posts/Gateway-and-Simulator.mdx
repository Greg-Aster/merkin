Three connected subsystems in [`Greg-Aster/Ainekio-bot`](https://github.com/Greg-Aster/Ainekio-bot) sit between the physical `ESP32-P4` V2 robot (or V1 `ESP32-S3` baseline) and **[Ainekio OS](/posts/ainekio-os/)** ([embodied integration](/posts/metahuman-integration/)), giving both a real-time session owner and a workbench for calibration, teleoperation, and physics simulation:

1. **The Host Gateway**: Maintains the authenticated `protocol-v1` WebSocket link with the robot, tracks command sequence numbers and connection epochs, streams camera frames and bidirectional `16 kHz` PCM audio, commands on-chip `50 Hz` MicroDuck velocity twists, or streams `50 Hz` host neural gait frames.
2. **The Embodied Adapter**: Translates high-level intents from Ainekio OS into capability-checked robot commands, persists crash-safe SQLite action receipts, exposes a one-click pause/resume switch for Ainekio OS control, and forwards structured telemetry and body-contact events upward.
3. **Body Control & Cockpit HUD**: Serves both a full-viewport **Cockpit HUD** for live driving and obstacle awareness and engineering workspaces for 12-channel servo calibration, IMU leveling, Freestyle authoring, and over-the-air firmware staging.

The gateway stack runs on a desktop workstation or an offboard `Radxa Dragon Q6A` single-board computer, supporting direct local LAN access, automatic Wi-Fi hotspot fallback when away from a router, or connection through an optional remote tunnel.

## Cockpit HUD and Body Control workbench

| Workspace | What It Provides on V2 |
| --- | --- |
| **Cockpit HUD** | Full-viewport live view from the chin-mounted `OV5647` camera overlaid with **pyramidal Lucas-Kanade optical-flow + monocular depth ground-contact obstacle range**, compact 12-servo tracking health, `LSM6DS3` attitude and `2S` battery readouts, an **On-chip MicroDuck vs. Host neural gait** selector, and a top-bar **Ainekio OS control** toggle |
| **Manual Locomotion & Postures** | Direct triggers and live parameter sliders (`Speed`, `Stride %`, `Motion rate`, steering heading, speed multiplier, and clean gait `Finish`) for `Stand`, `Walk`, `Run`, `Crawl`, 6-direction `Crab`, and 23 finite gestures |
| **12-Channel Servo Feedback** | Live commanded-versus-measured shaft angles across `CD74HC4067` channels `C4–C15` (`GPIO49` / `ADC2_CH0`), One-Euro velocity filter diagnostics, per-servo calibration curves, and closed-loop `Stand` (`2 mm` settle) / `Walk` arrival checks |
| **IMU Attitude & Leveling** | Live `208 Hz` `LSM6DS3` roll/pitch telemetry, one-click level-reference capture, 256-sample stationary gyro bias calibration, and self-leveling gain/damping tuning |
| **Freestyle Motion Library** | SQLite-backed editor and test runner for **349 curated 12-servo motions**—paired with the **489-row** training dataset (**73** library motions + **416** synthesized fault-recovery trajectories ending in `Stand`) |
| **Neural Gait & OTA Maintenance** | Compiles `107.8 KB` `int8` policies for Core 1 `50 Hz` on-chip execution, streams host MJX RL policies with synchronized telemetry logging, manages microSD video clips, and stages `ESP32-P4` firmware updates over Wi-Fi |

## Command translation and idempotent receipts

When Ainekio OS dispatches an intent across the embodied bridge, the gateway adapter maps it onto the connected robot's verified capabilities:

| Cognitive Intent / Event | Gateway & Adapter Execution Path |
| --- | --- |
| **Postures & Locomotion Goals** | Dispatches a checked posture, gesture, or measured distance/turn/visual walk (analytical solver or on-chip `50 Hz` MicroDuck) and monitors progress until terminal `Finish` |
| **Freestyle Programs** | Validates and streams a multi-target 12-DOF sequence, waiting for 4th-wire shaft arrival at each phase boundary |
| **Correlated Snapshots** | Captures an explicit still frame—or attaches a post-motion verification photo immediately before `done`—and returns the matched JPEG |
| **Robot Speech (TTS)** | Paces synthesized Kokoro or Piper `16 kHz` PCM bursts to the `ES8311` / `NS4150B` speaker queue while holding a self-speech suppression window so wake detection ignores playback |
| **Spoken Utterances (STT)** | Packages `WakeNet9s` + VAD speech segments as WAV audio (optionally paired with a contemporaneous camera frame) for local or LAN Whisper transcription |
| **Body-Contact Events** | Forwards thresholded `tipped`, `shaken`, and `stalled` events to Ainekio OS's fast 6-turn reflex workflow while absorbing routine health ticks into live status |

To guarantee that a brief Wi-Fi drop never triggers duplicate physical motion, every dispatched action is recorded in SQLite with its action ID, payload hash, connection epoch, and sequence number before transmission. Late completions settle the waiting task cleanly without re-sending the movement command.

## MuJoCo hardware twins (and the retired July browser simulator)

This page's URL (`gateway-and-simulator`) dates back to July 2026, when an early browser keyframe simulator was tested alongside the first gateway prototype. That browser-based keyframe simulator proved inadequate for real contact physics and was retired once physical V1 and V2 bring-up began (historical notes remain in the [V1 Archive](/posts/archive/motion-systems/)).

Today, simulation for Ainekio V2 runs in **MuJoCo (`MJCF`) and JAX / Brax / MJX** across **`4,096` parallel GPU hardware-twin environments**:

- **Exact 375-mesh CAD & four-bar physics**: Exports the `650 g` V2 assembly directly from Blender with closed-loop `35/20/28/38/55 mm` equality constraints, curved 3D-printed rocking soles, and Conjugate Gradient contact solving (`500 Hz` physics / `50 Hz` control).
- **Sensor & actuator fidelity**: Replicates the `MG90S` speed-torque ceiling, `PCA9685` `4.07 µs` PWM quantization, 12-bit `CD74HC4067` ADC scan with rail sag and One-Euro filtering, `208 Hz` `LSM6DS3` attitude projection, multi-surface floor friction (`0.14–1.45`), and `21–40 mm` cable/rug ledges—matched against the C firmware so distilled `107.8 KB` policies transfer straight onto the physical `ESP32-P4`. See the [Gait Development Guide](/posts/gait-development/) for training results and floor videos.
